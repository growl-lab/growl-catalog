# GWLandscape Default Model Dataset (Log-Uniform Z) Setup

Steps to download the GWLandscape fiducial model dataset with a log-uniform redshift (Z) distribution and place it in the expected folder structure.

## Steps

1. Go to the [GWLandscape publication page](https://gwlandscape.org.au/publication/Q29tcGFzUHVibGljYXRpb25Ob2RlOjI3/).
2. From the **Model** option, choose **FIDUCIAL, LOG-UNIFORM Z**.
3. Download the file using the **DOWNLOAD MODEL DATASET** option.
4. Create a folder named `GWLandscapeDefault_v02_39_01`, and inside it, create a subfolder named `Log-Uniform Z`.
5. Move/rename the downloaded folder to `GWLandscapeDefault_v02_39_01/Log-Uniform Z`.

## Notes

1. There is really not much that can go wrong; just make sure to download the right file.
2. The file is approximately **1.25 GB** in size, so ensure that you have enough disk space beforehand.
3. As far as I know, this file does not come with any checksums, so make sure you have a stable internet connection and track the download progress in the browser.
